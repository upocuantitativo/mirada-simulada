Tu propia copia, gratis y en línea

La aplicación son ficheros estáticos: no hay servidor ni base de datos. GitHub Pages la publica gratis.

En diez minutos, sin instalar nada

  1. Crea una cuenta gratuita en github.com.
  2. Abre el repositorio del curso y pulsa Fork, y después Create fork.
  3. En tu copia, entra en Settings y luego en Pages.
  4. En Source elige Deploy from a branch, rama main, carpeta / (root), y pulsa Save.
  5. Espera uno o dos minutos y recarga. Tu web aparece arriba: https://tu-usuario.github.io/mirada-simulada/
Tu copia es pública. Sube solo material que puedas enseñar y nunca datos de tu empresa. Las capturas que uses dentro del laboratorio no se suben: se quedan en tu navegador.

Adáptala a tu empresa

Todo se edita desde la propia web de GitHub, con el icono del lápiz.

  • Audiencias: el bloque PERSONAS de js/motor.js. Cambia nombre, pregunta, tiempo y pesos, o añade la tuya.
  • Código de acceso: en js/comun.js, la constante HUELLA. Calcula la nueva en la consola del navegador con Acceso.fnv('TUCODIGO'). Es una barrera de cortesía: quien lea el código podría saltársela.
  • Casos: sustituye las imágenes de casos/ y sus zonas en data/casos.json.

Para quien quiera ir más allá

Recalcular el error del aparato con PyEtSimul

PyEtSimul simula un eye-tracker: ojo, cámara, luz y calibración. No predice dónde mira nadie: por eso aquí se usa solo para la capa de instrumento. Necesitas Python 3.11 o superior.

pip install pyetsimul
python tools/instrumento_pyetsimul.py

Si clonas su repositorio en Windows y falla por rutas largas, ejecuta antes git config --global core.longpaths true. Con pip no hace falta.

Ver la web en tu ordenador

python -m http.server 8000

Abre http://localhost:8000. Abrir index.html con doble clic no funciona, porque el navegador bloquea la lectura de los datos.

Proyectos en los que se apoya

  • PyEtSimul (GPL-3.0): error del aparato. Bifurcación del curso: upocuantitativo/pyetsimul. Se usa su resultado, no su código.
  • MSI-Net (MIT): red neuronal entrenada con datos de atención humana (SALICON). Se ejecuta en tu navegador con TensorFlow.js; el modelo va en modelos/msi-net/.
  • UEyes y DeepGaze: modelos de referencia entrenados con datos reales. Necesitan Python y GPU, así que aquí no se ejecutan.
  • WebGazer: eye-tracking con la webcam, para medir personas de verdad con menos precisión.
